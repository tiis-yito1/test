# PowerPointプレゼンテーション生成スキル

このスキルは、ユーザーから提供されたコンテンツドキュメントを**構造的に解釈**し、テキストだけでなく、**必要に応じて図を自動生成**しながらPowerPointプレゼンテーションを作成する手順をエージェントにガイドします。

## 必須要件
- `python`, `pip`, `npm`が利用可能な環境。
- `python-pptx`, `@mermaid-js/mermaid-cli`ライブラリ。

## ワークフロー

### 1. インプットとテンプレートの準備
- **コンテンツドキュメント**と**出力ファイル名**をユーザーに尋ねます。
- **テンプレートの配置を確認・依頼します:** `assets/template.pptx` が存在するか確認し、なければユーザーに配置を依頼します。

### 2. コンテンツの知的分析と図の自動生成・提案
ここがこのスキルの核心です。ドキュメントを読み込み、スライド単位に分割した後、各スライドで以下の知的処理を行います。

1.  **構造分析:** スライドの本文テキストを読み込み、「箇条書きか」「プロセスの説明か」「階層構造か」などを分析します。

2.  **図解の提案:**
    - テキストが**フロー、依存関係、階層**など、図で表現した方が分かりやすい構造を持っていると判断した場合、エージェントは**自らMermaidコードを生成**し、ユーザーに図の挿入を提案します。
    - **対話例:**
      > **エージェント:** 「資料の『〇〇から△△へデータが流れる』という部分は、フローチャートにするとより分かりやすくなるかと思います。以下のような図を生成してスライドに挿入してもよろしいでしょうか？」
      > 
      > **提案するMermaidコード:**
      > ```mermaid
      > graph TD;
      >   〇〇 --> △△;
      > ```

3.  **ユーザー承認と画像化:**
    - ユーザーが提案を承認したら、提案したMermaidコードを画像ファイル（例: `/tmp/slide_X_diagram.png`）に変換します。
      ```bash
      # 提案したコードを一時ファイルに保存
      write_file(file_path="/tmp/temp_diagram.mmd", content="graph TD; 〇〇 --> △△;")
      # mmdcで画像化
      ./node_modules/.bin/mmdc -i /tmp/temp_diagram.mmd -o /tmp/slide_X_diagram.png -w 1280 -H 720
      ```
    - このスライドでは、元のテキスト本文は削除（または要約）し、生成した画像パスをスライドデータに追加します。

### 3. 構造化データの最終化
上記ステップを経て、各スライドの情報を以下のJSON形式にまとめ、一時ファイル `/tmp/content.json` に保存します。

```json
[
  // テキストのみのスライド
  { "title": "...", "content": { "body": "..." } },
  // 図を自動生成したスライド
  { "title": "...", "content": { "body": "（図の簡単な説明文など）" }, "image": "/tmp/slide_X_diagram.png" }
]
```

### 4. Pythonスクリプトの実行
最終化されたJSONデータを基に、`scripts/create_presentation.py` を実行してPowerPointファイルを生成します。

```bash
python3 scripts/create_presentation.py 
  --data /tmp/content.json 
  --template assets/template.pptx 
  --output (ユーザーが指定した出力ファイル名)
```

### 5. 完了報告
生成されたファイルのパスをユーザーに伝えます。
