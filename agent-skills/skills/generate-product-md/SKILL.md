# プロダクトドキュメント生成スキル

## 概要

このスキルは、会議の議事録やディスカッションのメモといった非構造化テキストから、整形されたプロダクト概要のマークダウンファイル（`product.md`）を生成します。
同時に、定義された各要件の根拠となった原文をまとめたエビデンスファイル（`product_references.md`）も生成します。

## ワークフロー

1.  **入力の確認:** ユーザーの指示から分析対象のファイルパスを特定します。パスが不明瞭な場合は、ユーザーに確認を求めます。

2.  **ベストプラクティスの参照:** `references/product-best-practices.md` ファイルを読み込みます。これは、プロダクトの全体像を正確に捉え、各項目を適切に抽出するための重要なステップです。

3.  **テンプレートの読み込み:** `assets/product-template.md` ファイルを読み込み、出力ドキュメントの構造を取得します。

4.  **分析と統合（Synthesis）:** 提供された議事録を深く分析し、議論の**文脈と意図**を理解することに重点を置きます。この際、以下のルールを厳格に守ります。
    *   **推測の禁止:** 議事録に記載されていない情報や、明確に読み取れない内容を**推測して記述することは固く禁じます。**
    *   **未決定事項の明記:** 該当する情報が見つからない、または内容が不明瞭な場合は、空欄にせず `【要確認】` とドキュメントに明記します。
    *   **ガイドラインの参照:** `product-best-practices.md` のガイドラインを常に参照しながら、議論の中から以下の要素を特定し、関連する発言をグルーピングします。
        *   背景と課題
        *   目的とビジョン
        *   具体的な目標
        *   ターゲットユーザー: 誰のためのプロダクトか？ (例: 「全従業員」) **言及されている部署名や役割は、たとえ小さな言及であってもすべて正確にリストアップします。**
        *   主要な機能やコンセプト
        *   制約事項
    *   抽出・グルーピングした情報を基に、`assets/product-template.md` の各項目に対応する、プロフェッショナルで簡潔な文章を**再構成・生成（Synthesize）**します。

5.  **根拠の抽出:** 分析の過程で、`product.md`に記述した各項目の根拠となった議事録の原文を抽出します。どの項目のための引用かが分かるように、見出しをつけて整理し、`product_references.md`のファイル内容を生成します。
    *   例:
        ```markdown
        # 背景（課題）
        > （議事録からの引用1）
        > （議事録からの引用2）

        # 目的
        > （議事録からの引用3）
        ```

6.  **テンプレートへの反映:** 分析・統合した情報を`product.md`のテンプレートに埋め込みます。

7.  **ファイルの生成:** 完成した2つのマークダウンコンテンツをファイルに書き出します。
    *   **出力先フォルダ:** ユーザーからの指定があればそのフォルダを使用します。指定がなければ `output` という名称のフォルダを使用します（存在しない場合は作成）。
    *   **ファイル名:**
        *   要件定義書: `product.md`
        *   根拠ファイル: `product_references.md`

8.  **ユーザーへの通知:** 生成した2つのファイル（`product.md` と `product_references.md`）のパスをユーザーに伝え、処理が完了したことを通知します。

## リソース

*   **`assets/product-template.md`**: 最終的な出力ファイルのマークダウンテンプレートです。ドキュメントを構造化するためにこれを使用します。
*   **`references/product-best-practices.md`**: 効果的なプロダクト概要を記述するためのガイドです。**テキストを分析する前に、必ずこのファイルを読んでください。**
